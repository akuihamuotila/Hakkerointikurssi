## x)

**Schneier 2015: Applied Cryptography, Chapter 1**

**1.1 Terminology - Historical Terms**

- Code vs. cipher: koodi operoi kielellisillä yksiköillä (sanat, lauseet) ja toimii vain ennalta määrätyissä tilanteissa. Salakirjoitus (cipher) toimii missä tahansa tilanteessa bitti- tai merkkitasolla.
- Kerckhoffsin periaate: turvallisuuden täytyy perustua avaimeen, ei algoritmin salaisuuteen. Jos algoritmi paljastuu, koko systeemi ei saa kaatua.

**1.4 Simple XOR**

- XOR on symmetrinen: `P XOR K = C`, `C XOR K = P`. Sama operaatio salaa ja purkaa.
- Käytännössä turvaton: englanninkielinen plaintext ei ole satunnaista, joten tilastolliset säännönmukaisuudet säilyvät salatekstissä ja paljastavat avaimen.

**1.7 Large Numbers**

- Suuri avainavaruus tekee brute-forcesta laskennallisesti mahdottoman. 2¹²⁸ operaatiota kestäisi miljardilla rinnakkaisella prosessorilla yli 10¹⁹ vuotta.

- Turvallisuus voi silti romahtaa kokonaan huonon toteutuksen takia, vaikka avainavaruus olisi riittävä.

## c)

hex encoded string:
`1b37373331363f78151b7f2b783431333d78397828372d363c78373e783a393b3736`

Salateksti on XOR:attu yhdellä tuntemattomalla tavulla. Koska mahdollisia arvoja on vain 256 (0-255), voidaan kokeilla kaikki brute-forcella. 

Oikea avain tunnistetaan pisteytysfunktiolla: dekryptattu teksti joka sisältää eniten englannin yleisimpiä kirjaimia (`ETAOIN SHRDLU`) on todennäköisimmin oikea.

Tämä johtuu siitä, että XOR on turvaton, koska plaintext ei ole satunnaista. Englanninkielisessä tekstissä tietyt kirjaimet esiintyvät paljon useammin kuin toiset.

Tämä tilastollinen rakenne säilyy vaikka teksti XOR:ataan, koska jokainen tavu salataan samalla avaimella. Eli koko tekstin saa auki vain yhdellä avaimella.

Käytännössä kun kokeilet väärää avainta, tulos on satunnaisen näköistä dataa jossa ETAOIN SHRDLU -kirjaimia esiintyy harvoin.

Kun kokeilet oikeaa avainta, tulos taas on englantia jossa ne esiintyvät usein. Pisteytysfunktio mittaa juuri tätä eroa.


Kirjoitin python-funktion:

```python
# muunnetaan hex-merkkijono raakabyteihin
salakirjoitus = bytes.fromhex("1b37373331363f78151b7f2b783431333d78397828372d363c78373e783a393b3736")

# pisteytysfunktio: laskee kuinka monta englannin yleisintä kirjainta tekstissä on
def pisteytä(teksti_bytes):
    yleisimmät = b"etaoin shrdluETAOIN SHRDLU"
    return sum(1 for byte in teksti_bytes if byte in yleisimmät)

# alustetaan muuttujat parhaan tuloksen tallentamista varten
paras_pistemäärä = 0
paras_tulos = None
paras_avain = None

# kokeillaan kaikki 256 mahdollista yksitavuista avainta
for avain in range(256):
    # XOR:ataan koko salateksti nykyisellä avaimella
    yritys = bytes([byte ^ avain for byte in salakirjoitus])
    # jos tulos sai enemmän pisteitä kuin edellinen paras, päivitetään paras tulos
    if pisteytä(yritys) > paras_pistemäärä:
        paras_pistemäärä = pisteytä(yritys)
        paras_tulos = yritys
        paras_avain = avain

print(f"Paras avain: {paras_avain}")
print(f"Paras tulos: {paras_tulos}")
```

Tuloste:
```
Paras avain: 88
Paras tulos: b"Cooking MC's like a pound of bacon"
```

Avain `88` on ASCII-merkki `X`. Pisteytys tunnisti oikean avaimen.

## d)

Latasin teksti-tiedoston cryptopals sivulta

Muokkasin edellisen kohdan koodin käyttämään tekstitiedostoa ja kokeilemaan kaikki avaimet (numerot 0-255) sen jokaiselle riville vuorotellen:

```python
# avataan tiedosto ja luetaan rivit
with open("ch4.txt") as tiedosto:
    rivit = tiedosto.read().strip().split("\n")

# sama pisteytysfunktio kuin c)-tehtävässä
def pisteytä(teksti_bytes):
    yleisimmät = b"etaoin shrdluETAOIN SHRDLU"
    return sum(1 for byte in teksti_bytes if byte in yleisimmät)

# alustetaan muuttujat parhaan tuloksen tallentamista varten
paras_pistemäärä = 0
paras_tulos = None
paras_avain = None

# käydään jokainen rivi läpi
for rivi in rivit:
    salakirjoitus = bytes.fromhex(rivi.strip())
    # kokeillaan kaikki 256 avainta jokaiselle riville
    for avain in range(256):
        yritys = bytes([byte ^ avain for byte in salakirjoitus])
        if pisteytä(yritys) > paras_pistemäärä:
            paras_pistemäärä = pisteytä(yritys)
            paras_tulos = yritys
            paras_avain = avain

print(f"Paras avain: {paras_avain}")
print(f"Paras tulos: {paras_tulos}")
```

Tuloste:
```
Paras avain: 53
Paras tulos: b'Now that the party is jumping\n'
```

Avain `53` on ASCII-merkki `5`. Pisteytys tunnisti oikean rivin ja avaimen.
