## b)

kopioin ```passtr.c``` -tiedoston lähdekoodin uuteen tiedostoon samaan kansioon tämän ```h3.md``` tiedoston kanssa

```c
// passtr - a simple static analysis warm up exercise
// Copyright 2024 Tero Karvinen https://TeroKarvinen.com

#include <stdio.h>
#include <string.h>

int main() {
	char password[20];
	
	printf("What's the password?\n");
	scanf("%19s", password);
	if (0 == strcmp(password, "sala-hakkeri-321")) {
		printf("Yes! That's the password. FLAG{Tero-d75ee66af0a68663f15539ec0f46e3b1}\n");
	} else {
		printf("Sorry, no bonus.\n");
	}
	return 0;
}
```

Ongelma on se, että salasana on selkokielinen C-merkkijono.
```c
strcmp(password, "sala-hakkeri-321")
```
Kääntäjä sijoittaa sen sellaisenaan binääriin ja näin ```strings``` lukee sen suoraan.

Eli korjatussa versiossa salasana ei saa näkyä suoaraan binäärissä

Tässä korjattu koodi:
```c
// passtr - a simple static analysis warm up exercise
// Copyright 2024 Tero Karvinen https://TeroKarvinen.com

#include <stdio.h>
#include <string.h>

int main() {
	char password[20];

	// puskuri oikealle salasanalle, joka rakennetaan ajon aikana
	char expected[20];

	// alustetaan merkkijono tyhjäksi ennen strcat-kutsuja
	expected[0] = '\0';

	// salasana jaetaan kahden merkin paloihin, jotta koko salasana ei esiinny binäärissä yhtenäisenä merkkijonona
	strcat(expected, "sa");
	strcat(expected, "la");
	strcat(expected, "-h");
	strcat(expected, "ak");
	strcat(expected, "ke");
	strcat(expected, "ri");
	strcat(expected, "-3");
	strcat(expected, "21");
	
	printf("What's the password?\n");
	scanf("%19s", password);
	// verrataan käyttäjän syötettä ajon aikana rakennettuun salasanaan
	if (0 == strcmp(password, expected)) {
		printf("Yes! That's the password. FLAG{Tero-d75ee66af0a68663f15539ec0f46e3b1}\n");
	} else {
		printf("Sorry, no bonus.\n");
	}
	return 0;
}
```
Eli nyt koodissa salasana jaetaan kahden merkin pätkiin binääriin, joten se ei löydy sieltä kokonaisuutena ```strings``` -komennolla

Nyt käännän koodin ajettavaksi binääriksi komennolla:
```gcc passtr.c -o passtr```
```
gcc = C-kääntäjä
passtr.c = lähdekoodi
-o passtr = binäärin nimi
```
Testataan

Ajetaan a) kohdan protokolla:

Komennolla ```strings -n 6 ./passtr``` Ei löydy samaan tyyliin salasanaamm, flagi löytyy vielä, mutta tehtävänannon mukaan sitä ei tarvinnutkaan piilottaa.

Ajoin myös komennon:
```strings -n 6 ./passtr | grep -F "sala-hakkeri-321"```
, jolla etsin suoraan salasanaa, ja silläkään ei löytynyt mitään.

Kokeilen vielä ajaa ohjelman, että salasana toimii:
```
$  ./passtr
What's the password?
sala-hakkeri-321
Yes! That's the password. FLAG{Tero-d75ee66af0a68663f15539ec0f46e3b1}
```
Ohjelma toimii ja printtaa flagin, mutta ei näytä salasanaa enää suoraan stringsillä.

Uusi lähdekoodi ja ajettava binäärimuotoinen ohjelma löytyvät tästä samasta kansiosta tämän h3.md tiedoston kanssa
